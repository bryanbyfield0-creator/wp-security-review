Fixed-price security reviews for WordPress plugin and theme authors, by Bryan Byfield.

- Offer page: https://bryanbyfield0-creator.github.io/wp-security-review/
- Sample report: https://bryanbyfield0-creator.github.io/wp-security-review/sample-report/
- Contact: bryanbyfield0@gmail.com

## What is in this repository

| Path | What it is |
|---|---|
| `index.html`, `style.css` | The offer page |
| `sample-report/` | A sample review (HTML and Markdown) of a demo plugin I wrote |
| `demo-plugin/` | The demo plugin with planted bugs (`demo-notes-board`) and the fixed version (`demo-notes-board-fixed`). **Do not install the vulnerable one on a real site.** |
| `checks/` | The script that tests each finding against a local install, and its output for both versions |

The sample report is not a review of any real plugin.
